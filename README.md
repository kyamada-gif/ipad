# IPアドレスの計算（試作2）

教材PDF「IPアドレスの計算方法」を、そのままアプリにしたもの。

```bash
cd ipcalc2 && open index.html
# うまく開けないときは
cd ipcalc2 && python3 -m http.server 8778    # → http://localhost:8778
```

サーバーもビルドも要りません。React は `vendor/` に同梱しています。

---

## 1. 背骨 ── 教材の手順に、暗記を足したもの

**軸は教材（PDF）です。**やり方は教材の2進数の手順そのまま。
そこに **「よく出るものを丸暗記させる」** という考えを足してあります。
教材に無い近道の解き方（256 から引いて刻み幅を出す、など）は**入れません**。

思想を1行で書くとこうです。

> **画面も・覚える中身も・進み方も、「いま思い出すこと」に効くものだけを、最小の形で置く。**

### どのステージも同じ3段

```
札を押す →「練習する」→ 説明の1枚 ──┬→「覚える」 暗記ドリル
                                    └→「テストをする」 演習10問
```

説明の1枚に出るのは3つだけです。

1. **つながり行** ── 前のステージで覚えた何を、ここでそのまま使うのか（1行）
2. **解き方** ── 何を覚えると、何が即答できるのか（1行）
3. **覚える表**（あるステージのみ）／覚える表が無いステージは、解いた跡の例

### 覚える表があるのは4ステージだけ

| ステージ | 覚える表 | 出どころ |
|---|---|---|
| 1 2の◯乗 | 2の2乗〜10乗（9枚） | **教材の「2進数の桁の重みの表」そのもの** |
| 4 プレフィックス長 ↔ サブネットマスク | /17〜/32 の両向き（28枚） | 教材に無い。頻出なので足した |
| 7 台数 → サブネットマスク | / → 使えるホスト数の階段（9枚） | 教材に無い。頻出なので足した |
| 10 ワイルドカードマスク | 255 から引いた8通り | 別枠（ACL と OSPF で使う） |

**閉じた集合が無いステージには、暗記ドリルを置きません。**
ルールが1行しかないステージに中間の段を作ると、それ自体が「操作に不要な機能」になります。

### 全体で1つの決まり

- **正解するまで、次へ進まない。**練習でもテストでも同じ。
  点になるのは**その問題の最初の答えだけ**（やり直しで全員が合格にならないように）
- **合っても外しても、根拠を小さく1行**出す
- **押せるものは4つ以下**
- 覚えさせるのは、**本番の答えに出てくる数だけ**

### 見た目の決まり（Apple の Human Interface Guidelines より）

- 文字は **7段だけ**（11 / 13 / 15 / 17 / 22 / 34 / 44）
- 色は **決めた32色だけ**。意味も1つに固定 ──
  青＝いま選んでいるもの／緑＝進む・できた／赤＝ちがう／黄＝区切りの線／灰＝まだ
- **色だけに頼らない。**選んでいるものは色に加えて太字にもする
- 小さい文字は **4.5:1 以上**のコントラスト。押すところは **44px** 以上

段や色を増やすと **`node build.js` が止まります。**画面ごとに少しずつずれていくのを防ぐためです。

## 2. 覚えることは3つの状態だけ

```
○ まだ            まだ5問中4問できていない
● 表を見てできた   5問中4問。次のステージが開く
★ 表なしでできた   もう一度やって、また4問。本番と同じ形
```

- 押すボタンはホームに **「つづける」1つ**。何をやるかはアプリが決めます
- **1セッション5問。**前半はやさしい数、後半は本番どおりの出方
- 間違えたときだけ、その場で手順が全部出ます
- **そのステージが初めてのときだけ**、教材の見本が自動で出ます（2回目からは「やり方を見る」）

**正解のあと**は、待たなくても画面を押せばすぐ次へ行きます（そのままでも自動で進みます）。
押した指がそのまま触れて豆知識を飛ばさないよう、0.3秒だけ効かないようにしてあります。

**練習で間違えたときは、同じ問題をもう一度やります。**手順は出したまま残るので、
それを見ながらなぞって、最後は「できた」で終われます。
点になるのは**最初の答えだけ**です（そうしないと、やり直せば誰でも毎回合格になり、
「5問中4問」に意味が無くなります）。2回やり直しても合わないときは「次へ」も出します。
**テストはやり直しません。**本番と同じ、一度きりの形にしています。

## 3. テスト（表なし）── 一度できたステージをもう一度やると

教材はこう書いています。

> この表は何度も使うことになるので、**自分で書けるようにしておくこと。**

だから **テストでは、桁の重みの表を出しません。**問いと、自分で計算する場所だけです。

ホームの一番上に **「練習」と「テスト」の切り替え**があります。押したほうが、
そのまま札を押したときの形になります。**選んだほうは覚えていて、開き直しても変わりません。**

切り替えると、ホームの見え方もそのほうに合わせて変わります。

| | 練習 | テスト |
|---|---|---|
| 盤 | 桁の重みの表を出す | 出さない。自分で計算する |
| ランプ | ○ まだ ／ ● できた | ○ まだ ／ ★ 表なしでできた |
| 「◯ / 7 できた」 | 表を見てできたステージの数 | 表なしでできたステージの数 |
| 「つづける」 | まだできていないステージ | まだ表なしでできていないステージ |

鍵のかかったステージは、どちらでも開きません。順番はひとつだけです。

```
今回は表なし。自分で計算します

2進数  00111100

┌ 計算 ────────────┐
│  32 ＋ 16 ＋ 8 ＋ 4  │
│                 60  │
│  7  8  9  ⌫         │
│  4  5  6  ＋        │
│  1  2  3  −         │
│  0     00  C        │
└────────────────┘
[ 60 で決定 ]
```

**計算するところは ＋ と − だけ**にしました。教材の手順に ×÷ は一度も出てきませんし、
本番に無い道具に慣れても仕方がないためです。
**どの重みを足す（引く）かを決めるのが人、足し引きの答えを出すのが機械。**
表を使う回とまったく同じ線引きです。

### 答えの入れ方は、ステージによって変えています

| ステージ | 入れ方 | なぜ |
|---|---|---|
| 1 | 計算した数がそのまま答え | 3桁までなので軽い |
| 2 | **重みの書いていない空の8マス** | 打ち間違いが起きない。どの桁がいくつかは自分の頭から出す |
| 3〜7 | **選ぶ（4択）** | **本番の CCNA も選択式。**アドレス2つを全部打たせると1問が重すぎる |

まちがいの選択肢は**よくある間違いから作っています。**でたらめな値は入れません。

| ステージ | 入れてあるまちがい |
|---|---|
| 3 | 使える範囲と取りちがえた／先頭と末尾が逆／線を1つずらした |
| 4 | ±1 を忘れた／片方だけ忘れた／線をずらした |
| 5 | **「2を足す」を忘れた**／1つ隣の長さ |
| 6 | **教材どおり「2を足した」**／1つ隣の長さ／基準のまま |
| 7 | 1ビット足りない・多い／まとめる前のまま／次のまとまり |

### 速さの記録は、表ありと表なしで別に持ちます

表なしは必ず遅くなるので、同じ物差しで比べても意味がないためです。

## 4. 教材と1か所だけ変えたところ

**6ステージ「必要なサブネット数からマスク」。**教材は必要な数に **2 を足して**いますが、
これはサブネットゼロが使えなかった時代の数え方です。
いまの CCNA では足しません。**このアプリは足しません。**

境界で答えがずれます（`/16` から延ばす場合）。

| 必要な数 | いまの試験 | 教材どおり | |
|---|---|---|---|
| 3個 | /18 | /19 | **ずれる** |
| 10個 | /20 | /20 | 同じ |
| 16個 | /20 | /21 | **ずれる** |
| 19個 | /21 | /21 | 同じ |
| 32個 | /21 | /22 | **ずれる** |

**5ステージの「台数に 2 を足す」は、いまも正しい**ので、そのままです
（先頭のアドレスと末尾のアドレスは、機器に付けられないため）。

アプリでは、6ステージを正解したときに1行だけ注が出ます。

## 5. 練習問題は、その場で作ります

教材の練習問題22問をそのまま出すことはしません。**数字を変えて無限に作ります。**
固定だと「252 = 11111100」を丸暗記してしまい、初めて見る数字で解けなくなるためです。

**やり方（見本）だけは教材の数字のまま**にしてあります。
読んだ直後に開いて「これだ」とつながるようにするためです。

出す長さは、原本4冊・全1650問に実際に出てきた回数に寄せています
（`/24` が232回でいちばん多い。詳しくは `out/full/IP計算アプリ_土台の洗い出し.md`）。

## 6. 答えが合っている根拠

### ① 生成器の答え

**Python の `ipaddress`** で作り直して突き合わせています。
同じ実装で検算しても同じ間違いをするだけなので、わざと別の言語・別の実装で照合しています。

```bash
node selftest.js 400 > /tmp/q.jsonl && python3 selftest.py /tmp/q.jsonl
# → 検算した問題  2800 問（7 ステージ × 400 問）
#    すべて一致。
```

### ② 画面を本当に描いて触る

ブラウザを開かずに、**アプリを描画して押します**（`.check/run.js`。jsdom を使用）。

```bash
node .check/run.js
# → 7ステージすべて：札が開く → 練習が始まる → わざと外すと手順が出る
#              → 正しく操作すると正解 → 結果が出る
#    テスト（表なし）：7ステージとも表が消え、計算するところが出て、正しく解ける
#    初めてのステージは教材の見本が自動で開く／2回目は開かない
#    5桁の重み（32768）は文字を小さくして収める
#    1ステージを解ききると、できた札が1つ増え、次のステージが開く
```

**確かめられないのは、見た目の大きさとはみ出しだけ**です（絵を描かない仕組みのため）。

検査は**決め打ちの秒数で待たない**ようにしています（「画面が出るまで」「問題が変わるまで」待つ）。
秒数で待つと、機械の速さによって結果が変わり、たまに落ちる検査になってしまうためです。

### ③ 盤の答え

**「正しく操作したら、その問題の答えになるか」**も機械で確かめています。

```bash
node build.js
# → 生成器の検査 OK（7 ステージ × 200 問）
#    盤の検査 OK（正しく操作すれば答えになる：1400 通り）
```

これができるのは、**画面と検算が同じ関数を使っている**からです
（`gen.js` の `splitOut` / `pickOut` / `stackOut`）。
画面側にも同じ計算を書くと、必ずどちらかがずれます。

この検査は「答えが合っているか」だけでなく、**その答えが盤の上で出せるか**も見ます。
実際、7ステージで「/24 のように区切りがオクテットの境目にくる問題」が出たとき、
盤には8つの桁しか並んでいないので線が引けず、**答えようがない問題**になっていました。
見るオクテットを1つ手前にずらして直し、線が1〜8ビット目の外に出たら止まるようにしました。

## 9. 前のアプリ（`ipcalc/`）との関係

**引き継いだもの**：Python での全件照合／札3状態と「つづける」1つ／1セッション5問／
前半はやさしく／盤に答えを刷り込まない／秒数を途中で見せない／
Apple の Human Interface Guidelines の数値（押すところ44px、文字は最小11px、コントラスト4.5:1）。

**変えたもの**：骨格を「16の操作」から **「盤1つ＋7ステージ」** に。
2ステージの向きを足し算から **引き算** に（教材と同じ向き）。
3ステージの入力を「幅＋つまみ」から **縦の線** に。
補助なしの回を「4択だけ」から **「表なし＋自分で計算するところ」** に。

**2つを並べたままにはしない予定です。**しばらく両方触って、手が伸びた方に寄せてください。

## 10. 直したところ（画面の確認で見つかったもの）

Fable 5 に判断してもらって直しました。

| 見つかったこと | 直し方 |
|---|---|
| **やさしい問題に `/12` が集中していた** | 3ステージ・4ステージのやさしい問題は `/17` 以上に限る。<br>`/12` は原本で1回しか出ないのに、候補が `/12 /20 /28` の3つだけで<br>3回に1回出ていた。いまは `/20` `/28` の2つ |
| `32768` が幅375pxでマスからはみ出す | 5桁のときだけ文字を11pxに（最小の決まりの範囲内） |
| 1ステージ・2ステージで、何も押さずに決定できた | 1つ以上押すまで押せない。<br>2ステージを「残りが0まで押せない」にはしない（合否を機械が教えてしまうため） |
| 7ステージで、まとめる対象が2つだけのことがあった | やさしいときは必ず4つ。後半は 2・4・8 を混ぜる |
| 1回目から「前より速い」と出ていた | 1回目は「いまの速さ」。2回目から「前より速い」 |
| 教材の見本にたどり着きにくい | **そのステージが初めてのときだけ自動で開く。**<br>ボタンも画面も増やさない（2回目からは小さいボタンのまま） |
| **答え合わせが画面の外に落ちていた** | 判定は「これで決定」より下に出ていたので、スマホでは見えなかった。<br>いまは**画面の下に貼り付く帯**。決定を押した直後、目も指もそこにある。<br>✓✕ の形と色の両方を出す（色の見え方は人によって違う） |
| 間違えたとき、正しい答えが手順に埋もれていた | 帯に**「答えは ○○」**を大きく出す。4択では正解が緑、押した外れが赤 |
| 7ステージで、答えようのない問題が出ていた | `/24` のように区切りがちょうど境目にくると、8つ並んだ桁の上に線が引けなかった。<br>見るところを1つ手前にずらして直した（約3.5%の問題が該当）。<br>線が8桁の外に出たら `build.js` が止まる |
| 「区切りのあるオクテット」が通じない | **マスクそのものを点ごと並べて、その数字を直接押す**形に。<br>上の材料欄は出さない（盤の中の数と別物に見えるため） |
| **255 でない数だけ明るくしていた** | 「255 じゃないところを見つける」という判断を機械が先にやっていた。<br>「光らせる手引きは入れない」と決めた方針に自分で反していたので削除 |
| 1ステージで「この2進数」がどれを指すか分からない | 問題の数と押すところが同じ見た目で縦に並んでいた。<br>左に名札、**枠を持つ／持たない**で見た目を分けた（列はそろえたまま） |

**分けたままにしたもの**：3ステージと4ステージ。盤は同じですが、3ステージはマスクが点表記で渡され、
4ステージは `/22` の形で渡されて「どのオクテットに区切りがあるか」を自分で判断します。
さらに「先頭と末尾は使えない、±1する」が加わるので、自動的にはできません。
ステージ番号が教材の①〜⑦とそのまま対応していることも、そのままにしています。

## 12. 引き継ぎ（次のセッションへ）

### いまの形

```
トップ画面（10ステージの札）
  └ 札を押す →「練習する」→ 説明の1枚
                              ├ チュートリアル（1問を最後まで手で解く）
                              └ 下に固定：[ 練習をする ] [ テストをする ]
                                              ↓                ↓
                                        盤で5問（表あり）   表なしで10問 → 9問で 🏅
```

ステージは10。1 2の◯乗／2 2進数→10進数／3 10進数→2進数／4 プレフィックス長↔サブネットマスク／
5 ネットワークアドレスとブロードキャストアドレス／6 使えるアドレスの範囲／7 台数→サブネットマスク／
8 サブネット数→サブネットマスク／9 まとめる（集約）／10 ワイルドカードマスク（別枠）

### 全体を貫く決まり（これを破らない）

1. **軸は教材PDF。**そこに「よく出るものを覚えさせる」を足したもの。**教材に無い近道の解き方は入れない**
2. **画面も・覚える中身も・進み方も、「いま思い出すこと」に効くものだけを、最小の形で置く**
3. **正解するまで、次に進まない。**練習でもテストでも同じ。点になるのは**最初の答えだけ**
4. **正解のマスを光らせる手引きは入れない／押せなくする跳ね返しも入れない**
5. **枠があるもの＝押せるもの。**押せないものは枠なしの平らな文字。**空きは破線**
6. **色だけに頼らない**（✓✕の形も出す）。青＝いま選んでいるもの／緑＝進む・できた／赤＝ちがう／黄＝線／灰＝まだ
7. **文字は7段だけ**（11/13/15/17/22/34/44）、**色は決めた32色だけ**。増やすと `node build.js` が止まる
8. **計算は `gen.js` に置く。**画面側で計算しない（答えの出どころを1つにするため）
9. **本番の言葉は正確に**（サブネットマスク・プレフィックス長・ネットワークアドレス・ブロードキャストアドレス・ホスト部・オクテット）。
   それ以外は中学1年生の言葉。「ビット目」「基準」は `build.js` が止める
10. **原理から外れる実装をするときは、事前に「外れます」と伝えてから**

### ステージ5の作り（いちばん手を入れたところ。他へ広げる見本）

```
① サブネットマスクを左から見て、はじめて 255 でなくなる数を押す   ← 押す
② サブネットマスクの 252 を 1 と 0 にすると    ← 機械が出す。引き算の過程を見せる
③ 同じオクテットの IPアドレス 219 を 1 と 0 にすると  ← 同上
④ 上の 219 の並びで、線から右を ぜんぶ 0 にする   ← 行ごと1回押す
⑤ おなじ並びで、線から右を ぜんぶ 1 にする       ← 同上
   この8つ ＝ 112　うしろは ぜんぶ 0
```
